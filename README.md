# יומן אימונים

אפליקציית מעקב אימונים אישית (PWA) לאייפון. עובדת בלי אינטרנט, הנתונים נשמרים רק במכשיר.

- **טכנולוגיה:** React + Vite + TypeScript, ‏Dexie (IndexedDB), ‏vite-plugin-pwa (Service Worker)
- **תמונות תרגילים:** [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (נחלת הכלל). את Cable Lateral Raise ציירתי כ-SVG.

## הרצה מקומית במחשב

```bash
npm install
npm run dev
```

ואז לפתוח את http://localhost:5173/gym-tracker/

## איך מעדכנים את האפליקציה אחרי שינוי

כל `git push` לענף `main` בונה ומפרסם אוטומטית ל-GitHub Pages (תוך 1-2 דקות).
באייפון, הגרסה החדשה נטענת בפעם הבאה שפותחים את האפליקציה (לפעמים צריך לסגור ולפתוח פעמיים).

## התקנה על האייפון

1. לפתוח ב-**Safari** את הכתובת `https://<שם-המשתמש>.github.io/gym-tracker/`
2. ללחוץ על כפתור השיתוף (ריבוע עם חץ למעלה)
3. לגלול ולבחור **"הוסף למסך הבית"** ← "הוסף"
4. לפתוח את האפליקציה פעם אחת מהאייקון כשיש אינטרנט, ולחכות כמה שניות. מעכשיו היא עובדת גם במצב טיסה.

## גיבוי

הגדרות ← "ייצוא גיבוי" ← "שמור בקבצים" (מומלץ ל-iCloud Drive). שחזור: הגדרות ← "שחזור מקובץ גיבוי".
כדאי לגבות פעם בחודש. האפליקציה תזכיר לך.

## מבנה הקוד

```
src/
  db.ts            מבנה הנתונים (Dexie)
  seed.ts          התוכנית ההתחלתית, התרגילים והדגשים
  lib/             לוגיקה: התחלת אימון, סטטיסטיקות, גיבוי, טיימר וצליל
  components/      רכיבים משותפים (Stepper, טיימר מנוחה, גרף, ...)
  screens/         המסכים
public/exercises/  תמונות התרגילים (נשמרות אופליין)
```
